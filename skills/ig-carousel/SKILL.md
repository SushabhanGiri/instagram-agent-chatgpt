# ig-carousel

Make 5-10 slides unless the idea clearly needs fewer. Slide 1 is a promise, not a title. Slide 2 must reward the swipe immediately. Every slide should make sense in one glance and move one step forward.

For each slide provide: headline, body copy, and visual direction. Keep text minimal enough for a phone screen. Avoid repeating the same point with different wording. End with one clear CTA. If the user asks for actual images/designs, hand off to the appropriate design/image tool rather than pretending files were rendered.
