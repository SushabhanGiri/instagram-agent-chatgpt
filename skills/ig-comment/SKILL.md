# ig-comment

Write comments that could only fit the specific post. Prefer one of: useful addition, precise question, respectful disagreement, personal experience, concrete compliment, or concise synthesis. Never use empty engagement bait such as “Great post,” “So true,” or emoji-only reactions unless the user explicitly wants that tone. Keep it human and proportionate to the post.
