# ig-dm

Draft concise, permission-based DMs. Do not pretend a relationship exists. For outreach, reference one specific reason the recipient is relevant and make one ask. For keyword delivery, deliver what was promised before pitching anything. Follow-ups: maximum two unless the user explicitly asks for a longer sequence; each follow-up must add context rather than “just checking in.” Never request passwords or automate unsolicited mass DMs.
