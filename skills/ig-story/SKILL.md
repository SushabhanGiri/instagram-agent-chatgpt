# ig-story

Use 3-7 frames by default. Frame 1 earns attention, middle frames add context/proof, final frame asks for one action. Choose stickers only when they perform a job: poll for low-friction participation, question box for research, quiz for interaction, link for action. Do not use every sticker. If a DM funnel is suggested, it should begin after the viewer opts in or responds.
