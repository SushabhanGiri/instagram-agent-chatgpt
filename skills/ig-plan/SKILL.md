# ig-plan

Plan for the user's actual production capacity. Choose 3-5 content pillars, then assign a purpose to each post: reach, trust, proof, conversation, or conversion. Mix formats only where they serve the idea. Give each planned item: day, format, topic, hook/cover, proof/source needed, CTA, and reuse opportunity.

Do not invent “best posting times.” If current audience analytics are available, use them; otherwise label timing as a test. Include a lightweight engagement routine, not spam quotas.
