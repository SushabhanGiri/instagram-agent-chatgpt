# ig-audit

Use the user's real analytics or connected Instagram analytics if available. Normalize performance where possible: views/reach versus account baseline, saves per reach, sends/shares per reach, follows per reach, and retention/watch-time measures for video. Do not compare raw views across accounts as if audiences were equal.

For each post identify: hook, promise, format, proof, pacing, CTA, and result. Separate evidence from hypothesis. End with “repeat,” “test,” and “stop” recommendations plus one next experiment.
